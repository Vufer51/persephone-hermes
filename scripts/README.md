# scripts — служебные скрипты

**Статус:** каталог зарезервирован. Скрипты появятся вместе с инфраструктурой Stage 0.

## Планируемые скрипты

| Скрипт | Назначение |
|---|---|
| `db/backup.sh` | резервная копия PostgreSQL |
| `db/restore.sh` | восстановление из копии (с подтверждением) |
| `db/migrate.sh` | применение миграций |
| `dev/bootstrap.sh` | подготовка локального окружения |
| `dev/check-secrets.sh` | проверка отсутствия секретов в рабочем дереве |
| `docs/check-links.sh` | проверка внутренних ссылок документации |

## Правила

- Скрипты не содержат секретов и не читают `.env` без явного указания.
- Разрушительные операции требуют подтверждения и не выполняются по умолчанию.
- Скрипты документируются в README или рядом с файлом.
- Скрипт, меняющий удалённый репозиторий или данные, требует явного согласия пользователя.

Реальные скрипты добавляются только вместе с проверенной функциональностью.
