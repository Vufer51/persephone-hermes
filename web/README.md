# web — Web Player

**Статус:** каталог зарезервирован. Frontend ещё не начат; стек будет выбран отдельным Issue/ADR.

Web Player — собственный интерфейс Persephone Music. Он использует только API Persephone и не обращается напрямую к Navidrome, Lidarr или Last.fm.

## Планируемые возможности

- поиск по каталогу;
- исполнители, альбомы, композиции;
- плейлисты и избранное;
- рекомендации и объяснения;
- радио;
- история прослушиваний;
- очередь и управление воспроизведением;
- настройки пользователя и привязка Last.fm.

## Правила

1. Секреты интеграций никогда не попадают во frontend.
2. Абсолютные пути файловой системы не используются.
3. Авторизация — через API Persephone, без прямой авторизации Navidrome.
4. Ошибки API отображаются понятно и не раскрывают внутренние детали.
5. Web Player не является обязательным для работы Subsonic-клиентов.

## Открытые вопросы

- выбор фреймворка и сборки;
- стратегия аутентификации (cookie-сессии или токены);
- поддержка офлайн-режима (не планируется в MVP);
- доступность и клавиатурная навигация.

Решение оформляется отдельным ADR перед началом Stage 7.
