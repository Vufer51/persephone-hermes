# ADR 0005: Web Player и Subsonic API совместимость

## Контекст

После реализации Stages 1-6 (Infrastructure, Users & Library, Playback, Last.fm, User Preferences, Recommendation Engine, Prefetch Engine) проект benötigt веб-интерфейс для воспроизведения музыки и совместимость с существующими Subsonic-клиентами.

Пользователи хотят:
- Воспроизводить музыку через веб-браузер (HTML5 аудио)
- Использовать существующие Subsonic-клиенты (Android, iOS, desktop)
- Видеть текущий трек (Now Playing) и историю воспроизведения

## Проблема

Нет веб-плеера для управления воспроизведением через браузер.
Нет совместимости с Subsonic API, что ограничивает возможность использования сторонних клиентов.

## Рассматриваемые варианты

### Вариант A: Полноценный фронтенд (React/Vue)
- Плюсы: riche UI, полный контроль над UX
- Минусы: требует отдельной сборки, деплоя, поддержки двух кодовых баз

### Вариант B: Web Player API + минимальный HTML5 плеер
- Плюсы: быстрое внедрение, совместимость с существующими Subsonic-клиентами, нет отдельной сборки фронтенда
- Минусы: базовый UI, требует внешнего плеера для полноценного опыта

### Вариант C: Только Subsonic API без веб-плеера
- Плюсы: максимальная совместимость с клиентами
- Минусы: нет встроенного способа воспроизведения через браузер

## Принятое решение

**Вариант B**: Реализовать Web Player API с HTML5 аудио поддержкой и Subsonic API совместимость.

Обоснование:
- Быстрое внедрение без отдельной сборки фронтенда
- Совместимость с существующими Subsonic-клиентами (Android, iOS)
- Web Player API позволяет любому клиенту подключаться
- Можно расширить полноценным фронтендом в будущем

## Последствия

### Положительные
- Веб-плеер доступен через `/api/v1/player/*` endpoints
- Subsonic-клиенты могут подключаться через `/rest/*` endpoints
- HTML5 аудио поддерживает Range запросы для seek
- Now Playing и история доступны через API

### Отрицательные
- Нет встроенного UI (требуется внешний плеер или браузер с прямой ссылкой на stream URL)
- Subsonic API реализует только подмножество endpoints (не все из полной спецификации)

### Риски
- Требуется Navidrome для фактического стриминга аудио файлов
- Без Navidrome stream URL возвращает локальный путь (заглушка)

## Статус

Accepted
